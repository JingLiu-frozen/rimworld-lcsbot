# 阶段 04 中期能源与升级（第 25-60 天）

目标：电力不再靠天吃饭，基地从"能住"变"好住"。

TASK 04-01 稳定电源
STEPS
1) `power` 看发电/耗电/储量
2) 研究地热，建地热发电机（全天候）
3) 地热没解锁前，太阳能 + 足够蓄电池过渡
4) 冷库、医疗、研究不能依赖单一电源
DONE 关键负载不断电，有储能缓冲

TASK 04-02 心情与美观
STEPS
1) `needs` / `mooddetail` 找最大扣分项
2) 娱乐 0% 是 -20，作息里必须有娱乐时段
3) 建餐厅 + 娱乐室，铺地板提升美观
4) 卫生间要有（卫生需求）
DONE 全员心情 > 50%，娱乐需求被满足

TASK 04-03 生产链
STEPS
1) 建锻造台、裁缝台、机械加工台
2) `bill` 加常用账单（零部件、医药、弹药）
3) 用 `work` 指派专人负责
DONE 能自产零部件与医药

DONE 判据：稳定电力、心情良好、生产链齐全 → `guide done 04_中期能源`
