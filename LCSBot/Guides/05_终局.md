# 阶段 05 终局（第 60 天以后）

目标：能扛住大规模袭击，并启动离开星球。

TASK 05-01 防御升级
STEPS
1) 围墙外挖陷阱阵（钢制或石制）
2) 加迫击炮应对围攻
3) 全员护甲升级（防弹背心 + 头盔）
DONE 能扛住 1000+ 点数袭击

TASK 05-02 飞船
STEPS
1) 研究星际航行相关科技
2) 收集飞船结构梁、推进器、反应堆材料
3) 建造飞船各部件并启动
DONE 飞船部件齐全

TASK 05-03 出发
STEPS
1) 全员上船
2) `askplayer` 请玩家执行起飞（这一步必须玩家操作）
DONE 玩家确认起飞

DONE 判据：能扛大规模袭击且有飞船 → `guide done 05_终局`
