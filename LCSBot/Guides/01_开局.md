# 阶段 01 开局（第 0-3 天）

目标：解禁物资、保住三条命、有床有饭。

TASK 01-01 解禁并盘点
PREREQ 已进地图
STEPS
1) `state` detail=brief 拿殖民者 ID、坐标范围
2) 对全图 `forbid {rect,on:false}` 解除开局物品禁掉状态
3) `vitals` 看每人技能；`health` 看有无伤口
DONE 物品不再 forbidden，已按技能定分工

TASK 01-02 床与房间
STEPS
1) `presets` 看有哪些房间预设；开局优先 `开局小屋`
2) `preset 开局小屋 <X> <Z> 0` 一次建出整间屋（含墙门床）
   —— 返回 placed/failed 与失败原因；被树石挡住的格子先 `designate` 清掉再重试
3) 没有合适预设时退回手工：`blueprint` 围墙 + `build Door` + `build SleepingSpot`
4) 屋顶靠墙围合自动生成，不要 `roof` 硬塞
DONE 每人有床，睡在室内

TASK 01-03 食物与工作
STEPS
1) `supplies` 看够吃几天；不足 3 天立刻开田
2) `growzone` 选肥沃地块种水稻（快熟）
3) `workorder` 拿一次槽位表，然后每人一次 `workset <ID> <1,1,3,...>` 整组设完
   —— 前四槽恒为 灭火/就医/医生/休养，都填 1
4) 技能不足的人不要给 1，2 已经够用
DONE 有种植区，全员 workset 已设，食物储备 > 5 天

FAIL 材料不足就先去采石/砍树，不要空等；连续两次失败换方案。

DONE 判据：三人有床、有饭吃、有田、工作排好 → `guide done 01_开局`
