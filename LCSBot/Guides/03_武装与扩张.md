# 阶段 03 武装与扩张（第 10-25 天）

目标：能打赢第一次像样的袭击，人口涨到 5-6。

TASK 03-01 防御
STEPS
1) 在门口建沙袋/掩体，形成交叉火力
2) 建 2-3 座炮塔（需要研究 GunTurrets）
3) 所有殖民者配枪：`vitals` 看射击技能，先配射击高的
DONE 门口有掩体，至少 2 座炮塔，人手一枪

TASK 03-02 医疗与温控
STEPS
1) 医疗室放医疗床 + 生命体征监测仪
2) `health` 检查慢性病、感染
3) 极端温度前先建加热器/制冷机
DONE 有医疗床，室温在 16-26℃ 之间

TASK 03-03 人口与科研
STEPS
1) 俘虏后 `rescue` 再招募；`askplayer` 处理接任务类
2) `researchinfo` 选下一个科技，`research` 设定
3) 优先顺序：蓄电池 → 太阳能 → 枪械 → 微电子
DONE 有稳定科研产出，人口 ≥ 5

DONE 判据：防御成型、医疗就绪、人口 5+ → `guide done 03_武装与扩张`
