# 阶段 02 过渡基地（第 3-10 天）

目标：从露天过夜变成有墙有门的封闭营地。

TASK 02-01 围墙与门
STEPS
1) 规划矩形围墙，把生活区全包进去
2) `blueprint {def:"Wall",rect,mode:"perimeter",stuff:"BlocksGranite"}`
3) 留两个开口，装门 `build Door x z`
4) 建完检查 `rooms` 确认闭合、屋顶已生成
DONE 生活区全封闭，有门，屋顶完整

TASK 02-02 仓储与厨房
STEPS
1) `presets` 里选 `仓库` 和 `厨房冷库`，按 13x13 边线对齐紧贴摆放
2) `preset 仓库 <X> <Z>` → 建完再 `preset 厨房冷库 <X2> <Z2>`，一次只建一间
3) 失败格子先清理（`designate Designator_FullyGrownTreesChop` / `Designator_Mine`）再重试
4) 装炉灶后 `bill` 加"简单餐"账单
DONE 有室内仓库与厨房冷库，食物不腐烂

TASK 02-03 电力起步
STEPS
1) `power` 看现状
2) 建 2 台风力发电机 + 1 蓄电池起步（不稳定但够用）
3) 电缆走墙内或地下，避免露天
DONE 关键设备（炉灶/研究台/灯）通电

FAIL 缺零部件就 `designate Designator_Mine` 采零部件矿，或先不用电改用燃料设备。

DONE 判据：围墙+门+仓库+厨房+通电 → `guide done 02_过渡基地`
