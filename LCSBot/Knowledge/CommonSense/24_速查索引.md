# 速查索引

先查状态，再查机制，最后才动手。左边是你要回答的问题。

## 状态类（本局实时数据）
| 问题 | op |
|---|---|
| 现在最急的是什么 | `alerts` |
| 刚刚发生了什么 | `messages` |
| 殖民地总览 | `state detail=brief` |
| 补给够吃几天 | `supplies` |
| 财富构成 | `wealth` |
| 矿在哪、多远 | `ore` |
| 田里情况 | `farm` |
| 电力盈亏 | `power` |
| 能建什么 | `buildables` |
| 研究能选什么 | `researchinfo` |
| 某人细节 | `pawn` / `vitals` / `needs` / `mooddetail` / `health` |
| 工作槽位顺序 | `workorder` |
| 房间是否闭合 | `rooms` |
| 区域 | `zones` |
| 有哪些预设房间 | `presets` |

## 常识检索（RimTalk 标签模型）
```
know {action:"find", q:"关键词"}        检索条目，返回 id/标签/重要性
know {action:"read", id:"ck-xxxx"}      取正文
know {action:"import", text:"..."}      导入 RimTalk 导出的 [标签|重要性]内容
know {action:"export", file:true}       导出给 RimTalk
```
格式说明见 `26_RimTalk常识兼容.md`。

## 数值类（本局真实值）
一律用 `codex`，不要凭记忆报数：

```
codex {topic:"food",q:"meal"}          食物营养与保质期
codex {topic:"cost",def:"Wall"}        材料与工作量
codex {topic:"work"}                   工作→技能
codex {topic:"stats",def:"Bed",stat:"MarketValue"}
```

## 顺序铁律
1. 有人流血/感染 → 先治
2. 火灾 → 全员灭火
3. 袭击 → 征召、进掩体、开火
4. 饥饿/崩溃 → 补食物与娱乐
5. 之后才是建造、研究、扩张

打断长期计划前把原计划写进 `note`，处理完读回来接着做。
