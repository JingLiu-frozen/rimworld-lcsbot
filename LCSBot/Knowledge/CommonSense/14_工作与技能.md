# 工作与技能（Work & Skills）

## 标准模式与手动优先级的区别
- **标准模式**：每格只有「绿勾/红叉」，勾上的才做；多件事都勾时，**越靠左的工作类型越优先**。
- **手动优先级**：每格填 1–4，数字越小越优先，**留空 = 永不做**；同为 1 时仍按左到右的顺序。
- 两种模式共有的铁律：**先把某一优先级下所有能做的工作干完，才会轮到下一级**。把搬运设成 1，小人会把全图的东西搬完才回来干正事，完全不考虑效率。
- 因此实操分层：灭火、就医、卧病这类救命工作留 1；常规生产（烹饪、种植、制造）2；建造、采矿、砍伐 3；搬运、清洁 4。**永远不要给搬运 1**。
- 用 `workset` 批量写多人的优先级；用 `workorder` 读某人当前槽位，改完立刻复核一遍。

## 1–4 的含义
- 1 = 最高，游戏优先扫这一级；4 = 最低，但**仍然会做**（不是不做）；空 = 不做。
- 同一级内部按工作类型的列顺序决定，再按该类型内部的子任务顺序决定，**不看距离远近**。
- 大类下面还有细分：就医→「灭火/采血」、救援→「医生/伤员后送」、建造→「采矿/割除」。细分顺序错了会出现「先干杂活、伤员躺地上流血」。
- 技能不够的人设 1 是危险的：他不会拒绝，只会做得很慢很差。

## 技能等级
- 12 个技能：射击、格斗、建造、采矿、烹饪、种植、动物、手工、艺术、医疗、社交、智力。等级 0–20。
- 高技能改变的东西因工作而异：建造是「速度 + 失败率」，医疗是「治疗质量 + 手术成功率」，手工/艺术是「品质」，烹饪是「食物中毒率 + 屠宰产量」，射击是「命中率」。
- **0 级仍可做**，只是极慢、易失败——这与「不能做」（incapable，工作格根本不显示）是两件事。不能做的来源是背景故事、特性、头衔、奴役、意识形态角色，多处会叠加。
- 分配前看工作格的边框：红框=低技能，白到亮黄=高技能，金框=极高；格内的小火苗是 passion。

## Passion 与经验
- 无 passion 只有约 35% 经验，单火约 100%，双火更高（wiki 的倍率表未随导出保留）。具体倍率用 `codex` 查本局真实值。
- passion 还提供做相关工作时的**心情加成**，所以让有 passion 的人干那一行，既快又不容易崩。
- 经验按**时间**累积，不按成果：干得更快不会让升级更快，只是同样的时间干了更多活。少数任务按次给经验（如治一个伤口）。
- 每个技能每天有净经验软上限（约 4000），超出部分只按 20% 计，所以狂刷一门技能收益递减。
- **10 级之后开始持续衰减**，等级越高衰减越快；掉到 0 经验后再扣 1000 才掉一级。Great memory 特性把衰减减半，Perfect memory 完全不衰减。
- 结论：与其养一个 20 级专家，不如养 2–3 个 9 级；唯一例外是「产出品质」的行当（手工、艺术），专家值钱。

## 哪些工作吃哪些技能
- 就医 Doctor → 医疗；手术、治疗、救援都走这条线。
- 管理 Warden → 社交（招降、审讯、处决）。
- 驯养 Handle → 动物（驯服、训练、挤奶剪毛）。
- 烹饪 Cook → 烹饪（做饭、屠宰；食物中毒率也看它）。
- 狩猎 Hunt → 射击。
- 建造 Construct → 建造（墙、家具、地板、拆解、屋顶）。
- 种植 Grow / 割除 PlantCut → 种植（播种、收割、砍树）。
- 采矿 Mine → 采矿（挖掘速度与矿物产量）。
- 锻造 Smith / 缝纫 Tailor / 制作 Craft → 手工（品质与最低技能门槛）。
- 艺术 Art → 艺术（只影响品质，不影响速度）。
- 研究 Research → 智力。
- **无关联技能**：搬运 Haul、清洁 Clean、灭火 Firefight、就医中的卧床 Patient/BedRest、基础工作 Basic（开关、开门、释放囚犯等）。
- mod 会加工作类型，本局真实绑定用 `codex {topic:"work"}` 查，别照抄 wiki。

## 几个关键判据数值（wiki）
- 建造：0 级只有 50% 速度，每级 +15%；「做坏了浪费材料重来」的概率从 75% 降到 8 级时 100% 成功。
- 烹饪：9 级食物中毒率最低，10 级屠宰效率最高，再往上只加速度。
- 手工：品质看技能，**生产速度不看手工等级**，看通用工作速度与账单工作量。
- 砍树 ≠ 割草：整图砍伐必须配 `area`，否则小人跑去地图边缘送死。

## AI 判据
- 每轮用 `workorder` 抽查 2–3 人：医生/灭火/卧病是否是 1；有没有人被安排在「无格」（无能力）的工作上。
- 出现伤员时的第一动作是确认「有 1 级且技能够的医生 + 有药」，而不是继续改生产队列。
- 搬运/清洁长期压在 4 时，注意库存爆炸与卫生崩盘（脏房间→感染），必要时临时抬到 3 跑一轮。
- 分配武器/岗位前先 `vitals` 看技能与移速：移速 0.15 的伤员别指望他撤退。
