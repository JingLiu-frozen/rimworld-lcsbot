# 怎么查真实数值

`codex` 直接从本局已加载的 Def 里读，不依赖 wiki。

| 想知道 | 命令 |
|---|---|
| 哪些食物最顶饱 / 保质期 / 市价 | `codex {topic:"food"}` ，可加 `q` 过滤 |
| 某个建筑要什么材料、多少工作量 | `codex {topic:"cost",def:"Wall"}` |
| 每个工作类型关联哪些技能 | `codex {topic:"work"}` |
| 任意属性值 | `codex {topic:"stats",def:"Bed",stat:"MarketValue"}` |
| 现在能建什么（已研究） | `buildables` 可加 `q` |
| 研究树与前置 | `researchinfo` |
| 有哪些设计器 | `designators` |

## 用法要点
- 不要猜 defName。先用 `defs {kind:"ThingDef",q:"床"}` 或 `buildables` 找到准确名字。
- 造之前先 `codex cost` 看材料，材料不够就先安排采集，别让蓝图干等。
- 分配工作前先 `codex work` 看该工作吃哪些技能，再用 `vitals` 看谁达标。
