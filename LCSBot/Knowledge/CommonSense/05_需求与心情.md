# 需求与心情（来自 wiki）

## 需求清单与失效后果
| 需求 | 不满足会怎样 |
|---|---|
| 食物 | 饥饿降心情 → 营养不良 → 死亡 |
| 休息 | 积累疲惫，最后当场倒地睡着；降心情、拖慢免疫力 |
| 娱乐 | 心情大幅下降（Joy 0% 约 -20） |
| 美观 | 轻度心情惩罚；满足时加成明显 |
| 舒适 | 坐硬椅子、睡差床会轻微不快 |
| 户外/室内 | 长期不出门/长期在户外都会越来越不开心（地下偏好者反过来） |
| 化学 | 有相关特质的人长期不碰药会不开心 |
| 学习 | 只对儿童；排程里必须有娱乐或自由时段 |

## 空间需求
- 判定范围：**7 格半径内可走到的格子**（满共 193 格）。
- **99 格以上 = 100% 满足；3 格以下 = 0%**。
- 可以走过去的家具/长椅/树**照样计入**；不能走的（如营养膏机）不算。
- **在户外时空间需求永远 100% 满足**。

## 娱乐是最大单项
- Joy 0% 直接约 **-20 心情**，比吃不好睡不好都狠。
- 作息里必须留娱乐时段，全排"工作"必然崩。
- 娱乐需要**多样化**，一直玩同一种会衰减。

## 心情崩溃
- 心情 < 35% 开始出问题，< 10% 会精神崩溃（伤人、纵火、游荡、暴食）。
- 崩溃期间不干活，还可能毁掉关键物资 → 预防远好于善后。

## AI 判据
- 每轮看简报里每个人的心情百分比。
- 有人 < 40% → `mooddetail` 找最大扣分项，优先修它。
- 常见大头：娱乐 0%、未埋葬的尸体、睡在户外、房间难看、饥饿。
