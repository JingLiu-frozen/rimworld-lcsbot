# 生存与安全优先级

任何时候按这个顺序权衡，上一条没解决不要做下一条：

1. **死亡风险**：流血、感染、低温症、窒息、失血倒地的殖民者
2. **即时威胁**：袭击、火灾、发狂动物、中毒
3. **需求塌陷**：饥饿、睡眠崩溃、心情 < 30% 即将崩溃
4. **基础设施**：床、食物来源、电力、医疗、仓储
5. **扩张与科技**：研究、生产、贸易、远征

具体阈值：
- 食物不足 3 天必须立刻安排种植或采集，不要等警报。
- 心情 < 35% 要查 `mooddetail`，娱乐 0% 是 -20 的大头。
- 尸体必须马上处理：未埋葬 -10、腐烂 -6、腐气致病。
- 医生/灭火/卧病的工作优先级必须是 1，否则伤员会流血流死。

紧急事件（袭击/火灾/救援）可以打断任何长期计划。打断前把原计划写进 `note`，结束后 `note` 读回来接着做。
